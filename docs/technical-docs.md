# Технічна документація Stellar Atlas 2.0

## Архітектура

Застосунок без складання (bundler-free): один `index.html`, статичні CSS і модулі ES2020. Зовнішня залежність — Three.js `0.186.1`, завантажується з CDN через модульний імпорт. Призначений для GitHub Pages і сумісних статичних серверів.

**Каталог:** `src/data/stars.js`, `src/data/planets.js`. Для нової зорі додайте унікальний `id`, спектральний клас, приблизні характеристики (K, L☉, R☉, M☉), `kind`, `track` та текст. `starList` будується автоматично.

**Сценарії:** `src/science/evolution.js`. Масиви для `solar`, `dwarf`, `massive`, `remnant` містять опорні етапи `at` (0–100), температуру, світність, радіус і опис. Між етапами використано геометричну інтерполяцію додатних величин. Шкала **не фізичний час**.

**3D:** `src/visual/scene.js`. Зоря має анімований фрагментний шейдер і світлову оболонку. Планети — сітки `SphereGeometry` з процедурними CanvasTexture. Пояс астероїдів — InstancedMesh. Орбіти — Line. Вибір планет — Raycaster. Камера керується сферичними координатами без OrbitControls. Планетні підписи — DOM-накладки з проєкцією 3D-позицій на екран.

**H–R:** `src/ui/hr.js` рендерить полотно Canvas 2D. Вісь температури логарифмічна зі спаданням праворуч, вісь світності логарифмічна. Бліда смуга головної послідовності схематична, без претензії на каталог Gaia.

**UI:** `src/app.js`, `assets/styles.css`: керування режимами, каталогом, фільтрами, оновлення панелей та шкали, адаптивний інтерфейс.

## Що реалізувати перед науково-дослідним використанням

- Зв'язати кожен параметр зорі з конкретним каталожним записом та оцінкою похибки (SIMBAD / Gaia / рецензовані дослідження).
- Замінити навчальні сценарії опублікованими обчисленими еволюційними треками з точними одиницями часу та маси.
- Відокремити видимі зображення об'єктів від модельованих поверхонь, якщо потрібні астрофізично реалістичні текстури.
- За потреби додати тестований AR-режим (WebXR або MindAR) як незалежний модуль, не змішуючи його з основним симулятором.
- Створити автоматизовані браузерні та візуальні тести, а також тест продуктивності на мобільних GPU.

Це навчальний прототип, не астрофізичний чисельний обчислювач.
