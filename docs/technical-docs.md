# Астросфера 3.0 — технічна документація

## Стек

Статичний вебпроєкт без bundler: `index.html`, CSS, JavaScript ES modules. Three.js 0.186.1 (MIT) імпортується через jsDelivr CDN. Для великої зоряної бази потрібна підтримка Web Workers, `fetch`, Streams та `DecompressionStream('gzip')` (Chrome/Edge сучасних версій).

## Модулі

- `src/data/stars.js`: 9 базових навчальних зір з орієнтовними атрибутами.
- `src/data/named-stars.js`: локальний покажчик 586 назв зі вторинної відкритої збірки (MIT, Cora Schneck). Унікальні записи без наукових параметрів позначаються `track:'unknown'`.
- `src/data/catalog.js`: розширення масиву STARS, пошук, фільтрація, злиття каталожних записів із локальними покажчиками назв, позначення невідомих значень.
- `src/data/hyg-worker.js`: під час натискання на кнопку завантажує HYG 4.0 `.csv.gz` (~13 МБ), розпаковує gzip і зчитує лише потрібні стовпці в окремому потоці; надсилає рядки в головний застосунок. Без backend-проксі, немає гарантованої доступності стороннього сервера.
- `src/data/planets.js`: довідкові характеристики восьми планет.
- `src/science/evolution.js`: умовні треки типів зоряної еволюції, зокрема `unknown` без вигаданого індивідуального сценарію; інтерполяція тільки для позитивних модельних величин.
- `src/ui/hr.js`: Canvas2D графік логарифмічних світностей і температур, обрана зоря виділяється, велика база семплюється для продуктивності. Немає уявлення, що це точна ізохрона або повний Gaia.
- `src/visual/scene.js`: Three.js, процедурний шейдер зорі, додаткові частинки плазми, спіральний диск, туманність та ударні хвилі, окремий режим Сонячної системи з процедурними текстурами й raycasting.
- `src/app.js`: єдине керування станом відтворення, масштабом, сценаріями, пошуком, відображенням атрибутів і переходами між етапами.

## Обмеження каталогу

**Іменована зоря ≠ перевірена фізична модель.** Початковий локальний індекс містить назви, але не вигадує даних. Згодом HYG може заповнити параметри. `temp` для великого каталогу — орієнтир за літерою спектрального класу, `temperatureEstimated:true`. `luminosity` з HYG є наближеною каталожною величиною, `luminosityEstimated:true`. Маса й радіус без прямого джерела — null. Класифікація `kind` за каталогом — евристична для навчального фільтра, а не астрофізичний висновок.

## Зовнішні API

У цій версії **немає** реального підключення до Gaia TAP, SIMBAD, NASA Exoplanet Archive або сервісу AR. Наявність посилань на них у документації не означає реалізації. Gaia DR3 містить понад 1.8 млрд астрономічних джерел; без зовнішнього backend, черг запитів і індексації клієнтський браузер не може завантажити все одночасно. Оновлення Gaia DR4 не підтягується автоматично.

## Тестування і подальша робота

Синтаксичні тести виконуються Node.js; базові тестові сценарії без WebGL перевіряють модуль еволюції та локальний каталог. Chromium і локальний вебсервер у середовищі підготовки блокуються на рівні мережевої політики; не можна стверджувати, що пройдено інтеграційні й GPU тести. Перед захистом перевірити в Chrome/Edge роботу WebGL, оновлення повзунків, вибір етапів, завантаження HYG (у вкладці Network), режим смартфона та відсутність помилок у консолі.
