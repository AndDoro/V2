# Посібник користувача — Астросфера 3.0

Докладні кроки запуску й керування наведено в кореневому файлі `README.md`.

1. Запустіть локальний сервер: `py -m http.server 8000` із папки проєкту; відкрийте `http://localhost:8000`.
2. Переглядайте Сонячну систему, переміщуючи мишу із затисненою лівою кнопкою. Для зручності використовуйте видимі кнопки `↶`, `＋`, `−`, `↷`, `⌂`. На смартфоні працює дотик.
3. Оберіть планету кнопкою з її назвою або натисканням на 3D-модель. Інформаційна панель праворуч покаже її навчальні характеристики.
4. Налаштуйте повзунок швидкості `×0…×5`; натисніть `▶`/`❚❚` для паузи чи відтворення. Кнопка **Спочатку** скидає налаштування.
5. Оберіть зорю з бібліотеки: на початку доступні 590 локальних записів, але докладні числові картки є тільки для дев'яти.
6. Застосуйте фільтр **Іменовані** або пошук. Додаткові записи без перевірених фізичних параметрів чесно позначені як неповні.
7. Для розширення бази натисніть **Завантажити великий каталог HYG**. Потрібен інтернет і сучасний браузер; архів приблизно 13 МБ. Після опрацювання можна шукати за HIP, HD, HYG або назвами.
8. У режимі **Еволюція зорі** переміщуйте шкалу, натискайте навігаційні кнопки етапів або запускайте відтворення. Швидкість `×0,5…×4` — тільки темп навчального показу, не справжня швидкість зоряної еволюції.
9. Відкрийте діаграму Герцшпрунга—Рассела праворуч; для великої бази це вибірка, а не повний графік усіх 119 тисяч об'єктів.

Клавіші: `/` — пошук; пробіл — пауза/відтворення; `←`/`→` — етапи; Esc — закриття мобільної панелі.

**Застереження:** швидкості, орбіти, розміри і сценічні ефекти умовні. Деякі спектральні класи/відомості з HYG дозволяють лише приблизну оцінку. Без повних вимірювань не можна обчислювати індивідуальну еволюцію зорі.
