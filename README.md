# Астросфера 4.0 — інтерактивна лабораторія Всесвіту

Навчальний вебпроєкт із 3D-моделлю Сонячної системи, каталогом іменованих зір, пошуком за каталоговими індексами, навчальними анімаціями зоряної еволюції та діаграмою Герцшпрунга—Рассела.

> **Важливо:** це педагогічна візуалізація, а не точна чисельна модель зоряної еволюції. Масштаб Сонячної системи навмисно нелінійний. Не кожен названий об'єкт має відому масу, радіус чи спектральний клас. **Жоден окремий каталог не містить усіх зір Всесвіту.**

## Можливості

- **590 локальних записів**: 9 розширених навчальних карток і 581 додаткова назва з опублікованої відкритої бази назв. Назва без перевірених фізичних параметрів не отримує вигаданих показників чи життєвого сценарію.
- **Великий каталог HYG v4.0** — завантаження приблизно 119 тисяч каталожних записів на вимогу (архів приблизно 13 МБ, потрібен інтернет). Не всі об'єкти мають власне ім'я — доступні HIP, HD, HYG, Bayer/Flamsteed та інші наявні позначення. Для величин, яких у джерелі немає, показується «Немає даних».
- Пошук, фільтри за назвою, навчальним класом, гігантами й залишками, посторінкове відображення великих результатів.
- **Сонячна система:** Сонце, вісім планет, орбіти, Місяць, кільця Сатурна й пояс астероїдів; процедура текстурування планет і анімація обертання.
- **Еволюційні навчальні схеми:** умовні траєкторії для сонячноподібних, маломасивних, масивних зір і білих карликів. Для невідомої фізичної класифікації сценарій не вигадується.
- **Синхронізовані елементи керування:** повзунок із кольоровим заповненням, пауза/відтворення, скидання, змінювання швидкості, вибір конкретного етапу, кнопки попереднього та наступного етапів.
- **Панель «ЖИТТЄВИЙ ЦИКЛ» згортається:** натисніть невелику кнопку `⌃` біля заголовка, щоб сховати повзунок, опис стадії та кнопки й звільнити місце для 3D-сцени. Кнопка `⌄` знову відкриває керування. Це працює також на смартфоні та в режимі Сонячної системи.
- **Помітне 3D-керування:** кнопки повороту, наближення, віддалення, повернення до початкового ракурсу, перетягування мишею/дотиком, колесо миші й вибір планет.
- **Анімовані зорі:** процедурні шейдери поверхні, корона, плазмові частинки, акреційний диск, туманності та умовні фронти ударної хвилі наднової.
- **Діаграма Герцшпрунга—Рассела для однієї вибраної зорі**: поточна точка умовного еволюційного стану переміщується за повзунком та під час відтворення; пройдений шлях показаний суцільною лінією, можливе продовження — приглушеним пунктиром. Об’єкти каталогу не накладаються один на одного на діаграмі. У режимі Сонячної системи відображається одна каталожна точка Сонця.

## Як запустити

**Потрібні:** актуальна версія Chrome або Edge, підтримка WebGL, доступ до інтернету для Three.js. Для HYG потрібні додатково `fetch` і `DecompressionStream('gzip')`.

Розпакуйте цей ZIP, у каталозі з `index.html` виконайте:

```bash
py -m http.server 8000
```

Відкрийте `http://localhost:8000/` у браузері. Альтернативно — **Visual Studio Code → Live Server**.

Для GitHub Pages помістіть вміст папки `astrosfera-v4` у корінь гілки, яку використовує Pages. Файл `examples/advanced-demo.html` залишено як переадресацію зі старого URL.

**Оновлення попередньої версії:** замініть **усі файли проєкту**, зокрема `index.html`, `assets/styles.css` і `src/app.js`. Не переносіть лише один HTML-файл. Якщо браузер продовжує показувати старий вигляд або не завантажує список зір, натисніть `Ctrl+F5` (або очистьте кеш для сторінки) і відкрийте її повторно.

## Спрощена версія для телефону

На екранах шириною до **730 px** залишаються видимими 3D-сцена, перемикач режимів та основна шкала відтворення. Бібліотека зір відкривається через кнопку **☰**. Кнопки **Планети** (лише для Сонячної системи), **Дані**, **H–R**, **Камера** відкривають окремі панелі поверх сцени — спочатку вони згорнуті. Кнопка **Етапи** розгортає довгий опис та навігацію етапами. Менший розмір текстур, нижча деталізація частинок і обмеження піксельного коефіцієнта знижують навантаження на мобільний GPU; це не гарантує роботу на кожному пристрої.

Щоб тимчасово прибрати **всю нижню панель**, натисніть кнопку `⌃` біля назви «ЖИТТЄВИЙ ЦИКЛ / Навчальний сценарій» (або «РУХ ПЛАНЕТ / Орбітальна симуляція»). Залишиться вузька смуга з кнопкою `⌄` для розгортання. Стан повзунка та анімації не скидається.

## Інструкція з керування

1. На початку відкривається Сонячна система; виберіть планету кнопкою під сценою або натисканням на 3D-об'єкт.
2. У панелі **КЕРУВАННЯ 3D** скористайтеся `＋`, `−`, `↶`, `↷`, `⌂`; можлива також навігація мишею/пальцем.
3. У нижній панелі змінюйте коефіцієнт швидкості обертання `×0…×5`. `▶` / `❚❚` — відтворення/пауза; **Спочатку** — скидання.
4. Виберіть зорю з каталогу ліворуч: відкриється її картка та умовний навчальний сценарій, якщо можна визначити тип.
5. Переміщуйте великий повзунок еволюції, використовуйте **Попередній/Наступний**, точки етапів або `▶`. `×0,5`, `×1`, `×2`, `×4` керують швидкістю демонстрації.
   За потреби згорніть увесь блок **ЖИТТЄВИЙ ЦИКЛ**, натиснувши кнопку зі стрілкою поряд із заголовком; повторне натискання відкриє його знову.
6. Розгорніть діаграму Герцшпрунга—Рассела. Вона відображає **лише вибрану зорю**, а в режимі еволюції — її умовний шлях і поточний маркер. Керування траєкторією здійснюється основним повзунком; клацання на H–R діаграмі більше не перемикає зорі.
7. Натисніть **Завантажити великий каталог HYG** для суттєвого розширення пошуку. Зачекайте завершення індексації в браузері. Після завершення доступний пошук за іменами, HIP, HD і HYG.

Клавіатура: `/` — пошук; `Пробіл` — пауза/відтворення; `←` і `→` — етапи в режимі еволюції; `Esc` — вихід із пошуку / закриття мобільного меню.

## Наукові обмеження

- **HYG 4.0:** зорі з кількох спостережувальних каталогів, переважно з околу Сонця; відомості неповні. Каталожну світність і оцінку температури за спектральною літерою не можна вважати точними прямими вимірюваннями. Відсутні маса/радіус не обчислюються з невідомих даних.
- **Gaia DR3:** понад 1,8 млрд джерел, але це не всі зорі Всесвіту і не всі джерела є зорями. Автоматичний доступ до Gaia TAP у цьому пакеті **не реалізовано**. [Архів Gaia](https://gea.esac.esa.int/archive/), [Gaia Data Release](https://www.cosmos.esa.int/web/gaia/dr3).
- **Сценарії й H–R траєкторії:** ілюстративні, відсоток не дорівнює віку. Кольорова суцільна лінія — *попередній умовний шлях*; пунктир — *можливе продовження*, а не персональний прогноз або результат спектральних спостережень. До утворення протозорі (на стадії газової хмари) H–R координати не показуються. Без точної маси, металічності та чисельної моделі неможливо визначити індивідуальну траєкторію зорі.
- **Білий карлик** та **залишки наднової:** температура не тотожна видимій яскравості. Показані анімації — умовні ефекти, не астрофотографії.
- **3D:** всі текстури та візуальні ефекти створено програмно. Сторонніх фото, скопійованих 3D-моделей чи чужих UI-шаблонів у пакеті немає.

## Перевірка

- JavaScript-модулі: перевірка синтаксису Node.js `node --check`.
- Логіку каталогу й навчальних треків: локальні функціональні тести `tests/` (окремо, без WebGL).
- **Обмеження тестування:** браузерний запуск Chromium/сервер у середовищі підготовки блоковано. Повний запуск WebGL і завантаження архіву HYG з мережі необхідно перевірити в реальному браузері користувача перед захистом. Відсутність браузерного тестування не приховано.
