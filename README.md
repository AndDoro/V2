# Stellar Atlas 2.0 — освітній інтерактивний атлас зір

Розширена версія навчального проєкту **«Моделювання еволюції зірок»**. Вона замінює головну сторінку та розширену демоверсію, зберігаючи навчальну ідею: спостерігати зорі, досліджувати їхні характеристики й порівнювати сценарії еволюції.

## Що реалізовано

- Каталог 9 іменованих реальних зір: Сонце, Проксима Центавра, Альфа Центавра A, Сіріус A, Вега, Арктур, Бетельгейзе, Рігель, Сіріус B.
- Пошук і фільтрація за типом зорі.
- Інтерактивна 3D-Сонячна система з **усіма вісьмома планетами**, їх обертанням навколо Сонця, орбітами, земним Місяцем, поясом астероїдів і кільцями Сатурна.
- Процедурні текстури планет, анімована поверхня зорі, світіння та зоряне тло.
- Збільшення, обертання камери, вибір планети й наближення до об'єкта.
- Два відокремлені режими: **«Сонячна система»** та **«Еволюція зорі»**.
- Еволюційні шляхи для зір сонячного типу, червоних карликів, масивних зір і білих карликів.
- Компактна діаграма Герцшпрунга—Рассела, яка розгортається за потреби. Температура зменшується зліва направо; світність подається в логарифмічній шкалі.
- Панель **поточних оцінюваних параметрів** зорі відокремлено від **умовних характеристик еволюційного етапу**.
- Адаптація інтерфейсу для мобільних пристроїв.

## Запуск

Рекомендовано розмістити всі файли **разом**, не змінюючи відносні шляхи. На GitHub Pages достатньо покласти каталог у корінь репозиторію та ввімкнути публікацію з гілки `main` (root).

Локально можна запустити сервер:

```bash
python -m http.server 8000
```

Потім відкрити `http://localhost:8000/`.

**Важливо:** потрібні сучасний браузер із WebGL і доступ до інтернету. Three.js завантажується зі стороннього CDN, версія зафіксована як `0.186.1`. Локальну копію бібліотеки в цьому пакеті не включено. При повністю автономному використанні необхідно додати її окремо й змінити URL імпорту в `src/visual/scene.js`.

Старе посилання `/examples/advanced-demo.html` автоматично перенаправляє на нову головну сторінку.

## Наукова коректність і межі моделі

1. **Параметри реальних зір — наближені.** Маса, радіус і світність не однаково точно визначені для всіх зір; особливо це стосується змінних надгігантів. Зокрема, значення для Бетельгейзе є характерними навчальними оцінками, а не точними результатами вимірювань.
2. **Треки еволюції — ілюстративні.** Це дискретні навчальні сценарії з інтерполяцією параметрів, **не** результат обчислення рівнянь зоряної структури, не ізохрони MIST/PARSEC і не реальний індивідуальний прогноз для обраної зорі. Відсоток шкали не є відсотком фактичного віку зорі.
3. **Реальна зоря ≠ навчальний сценарій.** Коли користувач рухає повзунок, панель із параметрами каталогу продовжує показувати поточні спостережувані оцінки. Вигляд анімованої зорі відображає обраний умовний етап.
4. **Умовний просторовий масштаб.** Розміри планет, їхні орбітальні відстані, розміри зір та орбітальні швидкості навмисно не подано в єдиному фізичному масштабі. Час руху планет прискорено і не дорівнює реальним періодам.
5. **Немає вигаданої «повної Сонячної системи» біля інших зір.** Вісім планет відображаються тільки для Сонця.
6. **Червоні карлики** живуть довше за нинішній вік Всесвіту, тому їхній віддалений фінал слід трактувати як теоретичний. Наслідок колапсу ядра масивної зорі залежить від конкретних умов; наднова, нейтронна зоря та чорна діра не є взаємозамінними гарантованими етапами.

## Технологічні зауваження

- Для графіки використано Three.js із JavaScript-модулями.
- Текстури генеруються в браузері алгоритмічно. У каталозі немає завантажених .glb/.gltf-моделей; це **процедурні 3D-моделі**, а не готові файли 3D-скульптур.
- Проєкт не є AR/MindAR-додатком. Цей пакет реалізує **інтерактивне 3D у веббраузері**; окремий AR-режим потребує додаткової реалізації та тестування на смартфоні.
- Наявність коду сама по собі не означає перевірку роботи на всіх відеокартах та мобільних пристроях.

Розроблено як прототип для навчальних занять і демонстрацій із астрономії та інформатики.
